# DefenseBioscope 🌍🚀

**Universal Global Defense Systems Coverage & Range Visualizer**

An interactive, high-performance 3D/2D planetary visualizer for military hardware coverage circles, missile strike ranges, air defense envelopes, fighter jet combat radii, and strategic blast zones — covering **every nation on Earth (195+ countries)** and powered by real-time live Wikipedia hardware intelligence.

---

## 🌟 Core Capabilities

- 🌐 **Universal Global Coverage (All Nations on Earth)**  
  Not restricted to select superpowers. Whether it's the United States, Russia, China, Turkey, Pakistan, India, Iran, North Korea, France, the UK, Germany, Israel, Japan, South Korea, Sweden, Italy, Brazil, South Africa, Ukraine, Taiwan, Poland, Egypt, UAE, Bangladesh, Indonesia, or **any other country on the planet** — if a weapon exists, it is supported.

- ⚡ **Future-Proof Real-Time Hardware Discovery (2026 – 2050+)**  
  Equipped with a live Wikipedia Client-Side Hardware Intelligence engine. Any new hypersonic missile, 6th-gen fighter, stealth drone (UAV), or next-gen air defense system announced or developed in the future is automatically searchable and instantly visualizable on the globe without waiting for manual app updates.

- 🎯 **215+ Pre-Loaded Verified Military Hardware**  
  Instant-deploy database of missiles (ICBM, SLBM, hypersonic, cruise, tactical), fighter aircraft combat radii, surface-to-air missile (SAM) defense umbrellas, stealth drones, and naval combatants.

- 🏢 **4,000+ Military Bases Across 190+ Countries**  
  Pre-mapped global military infrastructure — air bases, naval stations, missile silos, radar sites, and army installations across all continents with automated sync capabilities.

- 🌍 **3D Globe & 2D Flat Projections**  
  Seamlessly toggle between a full 3D interactive WebGL globe and a flat Mercator tactical grid with high-resolution satellite, dark, and light cartography.

- 💥 **Detonation & Tactical Blast Simulation**  
  Simulate operational ranges, combat radii, and tactical blast zones (heavy overpressure, thermal flash, and secondary damage contours).

- 📱 **Mobile-First Responsive Interface**  
  Flawless tactical interface on mobile devices with touch-optimized gesture bottom sheet drawers, zero button truncation, and complete parity with desktop PC.

- ⚡ **Ultra-Fast Performance Architecture**  
  Pure CSS zero-flicker loading screen, `React.memo` component memoization, 60ms GPU compositor transitions, and sub-second data rendering with zero lag.

- 🎨 **Instant Tactical Dark & Light Modes**  
  Instant toggle between deep stealth dark theme and high-contrast tactical light theme with zero FOUC (flash of unstyled content).

- 🛠️ **Custom Hardware Creator**  
  Define and deploy custom weapon specifications, experimental range parameters, and user-specified payloads directly onto the world map.

---

## 🛠️ Technology Stack

- **Frontend:** React 19 + Vite 8
- **Map & Geospatial Engine:** MapLibre GL + WebGL Globe Projection
- **Intelligence Source:** Wikipedia Real-Time Infobox Extraction Engine
- **Styling:** Custom Neumorphic Tactical Design System + Tailwind CSS
- **Deployment:** Standalone Single-File Distribution (`app.html`) & Modern Web App

---

## 🚀 Getting Started

### Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Compile single-file distribution & bundle
npm run build
```

This compiles both the standard web distribution and updates the self-contained `app.html` offline single-file executable.
